# MeteoLab

**Live weather data from school weather stations — for teachers and pupils.**

🌐 **Website: [meteolab.infp.ro](https://meteolab.infp.ro/edu_home.html)**

MeteoLab (MeteoEdu) is a free educational platform run by the **National Institute for Earth Physics
(NIEP), GeoEduLab**, Romania. It collects data from professional Davis weather stations installed at
schools and research sites in **Romania and Germany**, and turns them into material teachers can use in
class: live charts, ready-to-use datasets, exercises and a live class quiz.

It is developed within the Erasmus+ project **EASE — Educate, Act, Sustainably Share for the
Environment** (KA220-SCH), together with EAFC Nice, INSPE de Nice and the Richard-Hallmann-Schule
(Trappenkamp, Germany).

## What you can do on the website

| Page | What it is for |
|---|---|
| [**Home**](https://meteolab.infp.ro/edu_home.html) | Overview of the network and of the stations in each country |
| [**Explore**](https://meteolab.infp.ro/edu_explore.html) | Compare two stations side by side: temperature, humidity, pressure, wind, rain, solar radiation and UV, in local time |
| [**Exercises**](https://meteolab.infp.ro/edu_exercises.html) | 45 questions in three age groups (7–10, 11–14, 15–19), with explanations, points and badges |
| [**Download**](https://meteolab.infp.ro/edu_download.html) | Download data for one or more stations (up to 90 days) as an **Excel workbook with one sheet per station**, or as CSV; all readings or a daily summary, in °C, hPa and m/s |
| [**Teachers**](https://meteolab.infp.ro/edu_teachers.html) | Lesson activities (weather forecasting, maths, computer science, health), how to run the class quiz, and curated learning resources |
| [**Live class quiz**](https://meteolab.infp.ro/edu_quiz_host.html) | The teacher shows the questions on the projector; pupils answer on their phones by scanning a QR code |
| [**Join the network**](https://meteolab.infp.ro/edu_join.html) | How a school can get a station, with a siting guide based on the WMO standard |

The whole site is available in **English, Romanian, German and French**.

## Privacy

No accounts and no personal data are needed. Downloads are counted anonymously (station, period and
country only), fonts and libraries are self-hosted, and there are no cookies, ads or trackers. See the
[privacy policy](https://meteolab.infp.ro/edu_gdpr.html).
